# SQL Cipher Sandbox

Android-приложение-песочница: ведёт зашифрованную базу пользователей и записывает журнал событий телефонных звонков.

**Стек:** Kotlin, Jetpack Compose (Material 3), Hilt, Room, SQLCipher, EncryptedSharedPreferences.

## Возможности

- **Пользователи.** Список записей `name / phone`, добавление и редактирование через форму, удаление с подтверждением.
- **События.** Журнал изменений состояния звонка (`RINGING`, `OFFHOOK`, `IDLE`) с номером и именем собеседника, если номер есть в таблице пользователей.
- **ПИН-код.** Устанавливается при первом запуске и запрашивается при каждом входе в UI. После 7 неверных ПИНов подряд все данные приложения и выданные разрешения уничтожаются. Производный ключ PBKDF2-HMAC-SHA256 (600 000 итераций) одновременно служит ключом шифрования БД.
- **Шифрование.** БД Room зашифрована SQLCipher, соль и хэш ПИНа лежат в EncryptedSharedPreferences. Установки первой версии (SHA-256) автоматически переводятся на PBKDF2 при первом входе.
- **Навигация.** Боковое меню; после входа всегда открывается экран «Пользователи».

## Первый запуск

1. Запрос разрешений `READ_PHONE_STATE`, `READ_CALL_LOG`, `READ_PHONE_NUMBERS`. Шаг можно пропустить, но тогда события будут без номеров.
2. Установка ПИН-кода (4–8 цифр). Восстановить его нельзя, а 7 неверных вводов подряд стирают все данные.
3. Открывается экран «Пользователи».

## Сборка

```bash
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest   # юнит-тесты: PhoneMatcher, DAO, PBKDF2, PinManager
```

| Параметр | Значение |
|---|---|
| minSdk / targetSdk | 24 / 37 |
| AGP / Gradle | 9.4.1 / 9.6.0 |
| JDK | 17+ (подходит JBR из Android Studio) |
